현재 iPhone 및 iPad 버전의 자주 묻는 질문입니다.

무료 체험과 전체 게임은 무엇이 다른가요?

무료 다운로드. 한 번의 구매로 전체 게임을 잠금 해제합니다. 두 모드와 모든 보드·조각 외형을 사용할 수 있습니다. 무료 게임은 유효한 이동 100회 또는 더 이상 이동할 수 없을 때 끝납니다. 체험 진행 상황과 점수는 저장하지 않으며 설정은 유지합니다. 전체 게임은 턴 제한이 없으며 두 난이도별 세이브, 최고 기록, 선택적 iCloud 백업을 제공합니다.

진행 상황은 어디에 저장되나요?

전체 게임: 진행 상황은 기기에 저장됩니다. 설정에서 최고 기록과 두 난이도의 진행 상황을 iCloud에 백업할 수 있습니다. 복원을 확인하면 두 난이도의 진행 상황이 교체되며 난이도별 상위 12개 기록이 병합됩니다. iCloud에 변경 사항이 반영되기까지 시간이 걸릴 수 있습니다.

소리가 들리지 않아요.

설정의 사운드, 미디어 음량, 무음 모드와 오디오 출력을 확인하세요. 그래도 소리가 나지 않으면 사운드를 껐다 켜거나 앱을 다시 여세요.

게임 중 난이도를 바꿀 수 있나요?

전체 게임: 난이도마다 한 게임씩 저장합니다. 전환하면 현재 진행 상황을 저장하고 선택한 난이도를 이어 합니다. 저장이 없으면 새로 시작합니다. 실행 취소 옆 새 게임 아이콘은 확인 후 현재 난이도만 다시 시작하며 다른 난이도는 유지합니다.

게임이 끝나면 어떻게 되나요?

전체 게임: 마지막 보드, 점수와 턴이 그대로 표시됩니다. 다시를 누르면 결과를 기록하고 같은 화면에서 새 게임을 시작합니다. 종료는 결과를 기록하고 홈으로 돌아갑니다. 기록 닉네임은 선택 사항이며 키보드는 자동으로 열리지 않습니다.

로컬 데이터는 어떻게 삭제하나요?

설정 → 데이터 초기화에서 확인하면 저장된 게임, 점수, 선택한 닉네임, 플레이 통계와 설정이 삭제되며 되돌릴 수 없습니다. 앱에서 기기 백업을 관리할 수는 없습니다.

iCloud 백업은 어떻게 삭제하나요?

설정에서 ‘iCloud 백업 삭제’를 선택하고 확인하세요. 백업은 꺼지지만 기기 데이터는 유지됩니다. 백업을 끄기만 하면 기존 사본은 삭제되지 않습니다.
