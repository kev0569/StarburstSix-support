対象と現在のバージョン

この方針は、Starburst Sixと本サポートサイトでの情報の取り扱いを説明します。

無料版と完全版の違いは？

お試しの進行状況とスコアは保存・バックアップされません。設定は端末内に保持されます。

端末内データと任意のiCloud

進行状況、最高記録、任意の名前、設定、プレイ統計は端末内に保存します。1.5.1以降、初期状態でオフのiCloudバックアップを任意で有効にすると、最高記録、任意の名前、両難易度の進行状況を、バックアップ日時およびランダムな端末識別子とともに自分のApple iCloudアカウントに送信します。設定や累積プレイ統計は含みません。開発者のサーバーはバックアップを受信しません。広告・追跡SDKはありません。名前に機密情報を入力しないでください。

保存期間・削除・バックアップ

復元には手動確認が必要で、両難易度の進行状況を置き換え、各難易度の上位12記録を統合します。復元前の端末内コピーを残します。iCloudの転送は即時ではなく、有効なスイッチはサーバー受信の証明ではありません。オフや端末のリセットは既存のiCloudバックアップを削除しません。Apple Accountを変更すると再度有効にするまでバックアップを停止します。オフラインやiCloudのエラーで端末のセーブは削除されません。 このApple AccountのStarburst SixのiCloudバックアップをすべて削除しますか？バックアップはオフになり、端末の記録と進行状況は残ります。削除の反映には時間がかかる場合があります。

「設定 → データをリセット」で確認すると、セーブ、スコア、任意の名前、プレイ統計、設定が削除され、元に戻せません。端末のバックアップはアプリから管理できません。

ウェブサイトのホスティング

本サイトは GitHub Pages で公開しています。GitHub は安全のため訪問者の IP アドレスを記録します。本サイトは独自の解析、広告、Cookie、ブラウザ保存を追加せず、外部フォントやスクリプトも読み込みません。外部リンクにはリンク先の方針が適用されます。

プライバシーの質問とサポート連絡

開発者は端末内のゲーム記録にアクセスできません。サポートにメールを送る場合、送信元アドレス、本文、添付ファイルはお問い合わせの対応と回答に使用されます。メールは Outlook（Microsoft）が処理し、Microsoft のプライバシー方針が適用されます。サポートとのやり取りの削除を希望する場合は、メールでご連絡ください。機密情報は送らないでください。
